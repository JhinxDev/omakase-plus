# Interface captures

These WebP files are single-viewport captures from a live Omakase Plus server with private account, server URL, and connection details redacted:

- `omakase-plus-home-v6.webp`: Home view with sidebar navigation, featured title banner, and Continue Watching row.
- `omakase-plus-library-v6.webp`: Anime collection view with search, filters, and episode progress badges.
- `omakase-plus-movies-v6.webp`: Movies collection view with personal ratings.
- `omakase-plus-tv-v6.webp`: TV Shows collection with episode progress and personal ratings.
- `omakase-plus-requests-v6.webp`: Requests pipeline view for catalog discovery and tracking.
- `omakase-plus-settings-v6.webp`: Settings directory showing account, playback, language, and service sections.
- `omakase-plus-setup-v4.png`: Omakase Plus workflow and Bring Your Own Storage overview diagram.
