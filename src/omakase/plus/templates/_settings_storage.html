Local or NAS storage

Your disks, your media

{{ 'Server folder configured' if storage_local_configured else 'Available in local deployments' }}

Use media already on a local disk or a mounted NAS share. Real-Debrid is optional in this setup.

How to set up local storage
  1. Mount the disk or NAS share on the server running Omakase.
  2. Make its media folders available to Omakase and Plex through your deployment configuration.
  3. Start with import-only mode. Review a file import plan before adding it to the library.

NAS passwords and network mounts stay on the server. This page does not create shares or change existing media paths.

Local imports currently use the anime import workflow. General movies already indexed by Plex remain available through Movies.
