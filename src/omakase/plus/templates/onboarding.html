{% elif onboarding_setup_path == 'existing' %}

Use the services you already own

Omakase is the discovery and orchestration app. Plex is a separate playback server; download services and movie automation are separate too. Save an address reachable from the Omakase server and your credentials in Settings, then test explicitly. Connecting does not install software or move media.

{% else %}

Optional Plex, with an operator in control

Docker must already be installed on your server. Prepare app data and media directories, private configuration and the encryption key using docs/local-storage-plex-setup.md in the repository. Then review the configuration before starting the existing Plex profile:

docker compose --env-file .env.local -f compose.local.yaml --profile plex config --quiet
docker compose --env-file .env.local -f compose.local.yaml --profile plex up -d

Open Plex on the Docker host at http://127.0.0.1:32400/web, sign in and claim your server yourself. Create your libraries, then connect and test Plex below. This guide installs nothing, claims no account and changes no host or NAS mounts.
