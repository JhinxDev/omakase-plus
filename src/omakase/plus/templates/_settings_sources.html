AnimeTosho metadata

AnimeTosho is an optional server-managed source of anime release metadata. It does not use a saved personal API key. The Prowlarr filters above do not configure or disable AnimeTosho.

If its latest search failed, review the saved receipt in Service health. This may be a temporary upstream or network problem; the receipt does not establish a disconnected account.

Administrator setup and disabling

The server setting OMAKASE_ANIMETOSHO_ENABLED=true enables this optional source. Ask your server administrator to review upstream connectivity and the saved failure before changing the deployment.

To disable only this source, the administrator can set OMAKASE_ANIMETOSHO_ENABLED=false in the deployment configuration and apply it through the normal reviewed deployment process. Keep existing service restrictions and source cooldowns intact. This page does not apply that change.

Existing media, personal history and other configured sources are separate from this optional metadata source.
