OMAKASE_PLUS_PRIVATE=true omakase plus agent --data-dir /path/to/app-data --user-id {{ agent_user_id }} status
Docker or source install

For the portable Compose setup, run in its existing container:

docker exec -i omakase-local-app omakase plus agent --data-dir /home/omakase/data --user-id {{ agent_user_id }} status

An existing private deployment may name its container omakase-plus; use your configured container name. The source command above uses a POSIX shell. Set OMAKASE_PLUS_PRIVATE=true in the environment for every source invocation.

Connect an MCP client

Install the optional agents package extra, then use the same command ending in mcp. Your client launches it locally, through Docker, or over authenticated SSH. The standard Docker image already includes the extra.
